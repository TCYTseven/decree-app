Commands

Every command and flag, taken from the CLI's own help output.

Every block on this page is the literal --help output of decree-harness 0.1.0.

Global options

decree-harness --help
Usage: decree-harness [options] [command]

Scan a codebase and generate an AI agent harness for it: prompt, tools, subagents, guardrails and
evals.

Options:
  -v, --version                   print the version
  -C, --cwd <dir>                 run as if decree was started in <dir>
  --verbose                       print debug output and stack traces
  --no-color                      disable colored output
  -h, --help                      show help

Commands:
  init [options] [dir]            scan, plan and generate a harness (the default command)
  scan [options] [dir]            scan the project and write .decree/profile.json
  plan [options] [dir]            scan + plan, writing decree.json only (no code)
  generate|gen [options]          render decree.json into runnable code
  refine [options] <feedback...>  change the harness in plain English (uses Claude), then regenerate
  chat [options]                  chat with your agent in the terminal (tools run locally)
  run [options] [prompt...]       run the agent once on a prompt (also reads stdin)
  eval [options]                  run the evals in decree.json and report pass/fail
  doctor [options]                check your environment, API key, decree.json and generated code
  tools [options]                 list the tools in decree.json
  decisions                       the team decisions the agent follows: extract them, confirm them,
                                  check what applies to a path
  schema                          print the JSON schema for decree.json
  preview [options]               open a local dashboard to inspect, edit and try the harness
  help [command]                  display help for command

Examples:
  $ npx decree-harness                                         interactive setup
  $ npx decree-harness init --yes --offline                    no prompts, no API key needed
  $ npx decree-harness init -g "Fix flaky tests" -t ts,mcp     set the goal and targets up front
  $ npx decree-harness chat                                    talk to the generated agent
  $ npx decree-harness run "Which orders are pending?" --json  one-shot run, JSON output
  $ npx decree-harness refine "make every tool read-only"      edit the harness in plain English
  $ npx decree-harness decisions for src/db                    decisions that apply to a path
  $ npx decree-harness eval --filter orders                    run a subset of the evals

decree.json is the source of truth: edit it, then run `npx decree-harness generate`. Installed
globally, the shorter `decree` command works too.

init

The default command. Running npx decree-harness with no command runs init. Interactive in a terminal; non-interactive with --yes or when stdin is not a TTY.

decree-harness init --help
Usage: decree-harness init [options] [dir]

scan, plan and generate a harness (the default command)

Options:
  -g, --goal <text>     what the agent should do, in your words
  -t, --targets <list>  comma-separated: typescript, python, mcp, claude-code (or all)
  --offline             use the heuristic planner instead of Claude
  -m, --model <id>      model for planning and the generated harness (default claude-opus-5)
  --no-critique         skip the critic pass (faster, cheaper)
  --api-key <key>       Anthropic API key (default: ANTHROPIC_API_KEY or .env)
  -o, --out <dir>       output directory for generated code (default: "agent")
  -y, --yes             non-interactive: accept defaults (automatic when not a TTY)
  -f, --force           re-plan an existing decree.json and overwrite files you edited
  --dry-run             show what would be written without writing anything
  -h, --help            show help
Terminal
$ npx decree-harness init --yes --offline
$ npx decree-harness init --goal "Triage failing CI runs" --targets typescript,mcp

scan

Deterministic and local. Prints a summary of what was found and writes .decree/profile.json.

decree-harness scan --help
Usage: decree-harness scan [options] [dir]

scan the project and write .decree/profile.json

Options:
  --json      print the profile as JSON
  -h, --help  show help
Terminal
$ npx decree-harness scan --json

plan

Like init without the code generation step. Useful for reviewing the spec before you generate anything.

decree-harness plan --help
Usage: decree-harness plan [options] [dir]

scan + plan, writing decree.json only (no code)

Options:
  -g, --goal <text>     what the agent should do, in your words
  -t, --targets <list>  comma-separated: typescript, python, mcp, claude-code (or all)
  --offline             use the heuristic planner instead of Claude
  -m, --model <id>      model for planning and the generated harness (default claude-opus-5)
  --no-critique         skip the critic pass (faster, cheaper)
  --api-key <key>       Anthropic API key (default: ANTHROPIC_API_KEY or .env)
  -y, --yes             don't ask before overwriting decree.json
  -h, --help            show help
Terminal
$ npx decree-harness plan --yes --goal "Answer questions about orders"

generate

Pure rendering from decree.json, no network. Alias gen.

decree-harness generate --help
Usage: decree-harness generate|gen [options]

render decree.json into runnable code

Options:
  -t, --targets <list>  override decree.json targets
  -o, --out <dir>       output directory (default: "agent")
  -f, --force           overwrite files you edited
  --dry-run             show what would change without writing
  --clean               remove previously generated files that are no longer produced
  --json                print what was written as JSON
  -h, --help            show help
Terminal
$ npx decree-harness generate --dry-run
$ npx decree-harness generate --targets python --clean

refine

Sends your feedback and the current spec to Claude, validates the result, then regenerates. Requires an API key.

decree-harness refine --help
Usage: decree-harness refine [options] <feedback...>

change the harness in plain English (uses Claude), then regenerate

Options:
  -m, --model <id>  model to use for refinement
  --api-key <key>   Anthropic API key
  -o, --out <dir>   output directory (default: "agent")
  --no-generate     only update decree.json
  -f, --force       overwrite generated files you edited
  --dry-run         show the diff without writing
  -h, --help        show help
Terminal
$ npx decree-harness refine "make every tool read-only"
$ npx decree-harness refine "add an eval for refunds" --dry-run

chat

Runs the harness in your terminal. Tools execute locally; tools that need approval ask first. /cost shows spend so far.

decree-harness chat --help
Usage: decree-harness chat [options]

chat with your agent in the terminal (tools run locally)

Options:
  -m, --model <id>  override the model in decree.json
  --api-key <key>   Anthropic API key
  --dry-run-tools   tools describe what they would do instead of executing
  -h, --help        show help
Terminal
$ npx decree-harness chat
$ npx decree-harness chat --dry-run-tools

run

One prompt, one answer. Reads the prompt from stdin when none is given.

decree-harness run --help
Usage: decree-harness run [options] [prompt...]

run the agent once on a prompt (also reads stdin)

Options:
  --json            print the full RunResult as JSON
  -y, --yes         auto-approve every tool call (dangerous)
  -m, --model <id>  override the model in decree.json
  --api-key <key>   Anthropic API key
  --dry-run-tools   tools describe what they would do instead of executing
  -h, --help        show help
Terminal
$ npx decree-harness run "How many orders are pending?" --json

eval

Runs each case in evals and checks expected tool calls, text, and the rubric (graded by a Claude judge). Tools are dry-run unless you pass --live-tools.

decree-harness eval --help
Usage: decree-harness eval [options]

run the evals in decree.json and report pass/fail

Options:
  --filter <text>    only run evals whose id contains <text>
  --live-tools       execute tools for real (default: dry-run)
  --concurrency <n>  evals to run in parallel (default: "2")
  -m, --model <id>   override the agent model
  --api-key <key>    Anthropic API key
  --json             print results as JSON
  -h, --help         show help
Terminal
$ npx decree-harness eval --filter orders

doctor

Checks Node, the API key, decree.json, env vars the tools need, and the generated output.

decree-harness doctor --help
Usage: decree-harness doctor [options]

check your environment, API key, decree.json and generated code

Options:
  --online         also check that api.anthropic.com is reachable
  -o, --out <dir>  output directory (default: "agent")
  --json           print results as JSON
  -h, --help       show help
Terminal
$ npx decree-harness doctor --online

tools

Prints the tool table: kind, safety flags, what each tool binds to and where it came from.

decree-harness tools --help
Usage: decree-harness tools [options]

list the tools in decree.json

Options:
  --json      print tools as JSON
  -h, --help  show help
Terminal
$ npx decree-harness tools --json

decisions

The team decisions the agent follows: ADRs, post-mortem lessons and rules from CLAUDE.md, AGENTS.md and Cursor rules. list (the default) shows them, extract re-reads the repo and keeps your statuses, for prints exactly what get_decisions returns for some paths, confirm makes proposed decisions live, and supersede retires one. Changes regenerate the harness when it was generated before.

decree-harness decisions --help
Usage: decree-harness decisions [options] [command]

the team decisions the agent follows: extract them, confirm them, check what applies to a path

Options:
  -h, --help                       show help

Commands:
  list [options]                   list the decisions in decree.json
  extract [options]                find decisions in ADRs, CLAUDE.md/AGENTS.md rules and
                                   post-mortems, and merge them into decree.json
  for [options] <paths...>         show what get_decisions returns for these files or directories
  confirm [options] <ids...>       mark proposed decisions live, so the agent follows them
  supersede|reject [options] <id>  retire a decision (with --by, name the decision that replaces it)
  help [command]                   display help for command
Terminal
$ npx decree-harness decisions
$ npx decree-harness decisions for src/db/users.ts
$ npx decree-harness decisions confirm rule-claude-md-never-write-raw-sql-outside-src
$ npx decree-harness decisions supersede adr-0002-use-mongodb --by adr-0003-store-events-in-postgres

schema

Prints the JSON schema for decree.json. decree also writes it to .decree/schema.json for editors.

decree-harness schema --help
Usage: decree-harness schema [options]

print the JSON schema for decree.json

Options:
  -h, --help  show help
Terminal
$ npx decree-harness schema > decree.schema.json
