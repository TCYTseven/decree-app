decree.json

The harness spec. Every field, its type and default, taken from the JSON schema.

decree.json lives at the root of your project. init and plan write it, refine changes it, generate renders it, and chat, run and eval execute it. It is validated on every load. Print the full schema with decree-harness schema.

decree.json (trimmed, from the orders fixture)
{
  "$schema": "./.decree/schema.json",
  "version": 1,
  "name": "acme-orders-agent",
  "goal": "Operate the orders API and triage test failures",
  "model": {
    "id": "claude-opus-5",
    "effort": "high",
    "subagentId": "claude-sonnet-5",
    "thinking": "adaptive"
  },
  "tools": [
    {
      "name": "delete_order",
      "description": "Permanently delete an order. Calls DELETE /orders/{id}. …",
      "kind": "http",
      "inputSchema": {
        "type": "object",
        "properties": { "id": { "type": "string" } },
        "required": [ "id" ]
      },
      "readOnly": false,
      "destructive": true,
      "requiresApproval": true,
      "http": {
        "method": "DELETE",
        "baseUrlEnv": "ACME_ORDERS_BASE_URL",
        "defaultBaseUrl": "http://localhost:3000",
        "path": "/orders/{id}",
        "auth": { "type": "bearer", "env": "ACME_API_TOKEN" }
      },
      "source": "openapi:DELETE /orders/{id}"
    }
    // … 17 more tools, plus subagents, evals, env
  ],
  "guardrails": {
    "maxTurns": 25,
    "maxCostUsd": 5,
    "approvalMode": "destructive",
    "allowedPaths": [ "." ],
    "redactEnv": [ "ANTHROPIC_API_KEY", "ACME_API_TOKEN", "STRIPE_SECRET_KEY" ]
  },
  "targets": [ "typescript", "python", "mcp", "claude-code" ]
}

Top-level fields

$schemastring
Path to the JSON schema. decree writes ./.decree/schema.json so editors can validate and autocomplete.
versionnumberdefault 1
Spec format version.
namestringrequired
Kebab-case slug. Used for package names, the MCP server name and the Claude Code agent file.
displayNamestring
Human-readable name used in prompts and READMEs.
descriptionstringdefault ""
Short summary of the agent.
goalstringdefault ""
What the agent is for, in your words. Set with --goal.
modelobject
Models and reasoning settings. See model.
systemPromptstringrequired
The main agent's system prompt (Markdown).
toolsobject[]default []
The tool surface. See tools.
subagentsobject[]default []
Agents the main agent can delegate to. See subagents.
guardrailsobject
Limits and approval rules. See guardrails.
contextobject
Context management. See context.
evalsobject[]default []
Eval cases. See evals.
targetsarray of "typescript" "python" "claude-code" "mcp"default ["typescript", "claude-code"]
What generate renders.
envobject[]default []
Environment variables the harness reads. Written to .env.example and checked by doctor.
provenanceobject
Written by decree: planner type (heuristic or llm), decree version, timestamp and planner notes.

model

model.idstringdefault "claude-opus-5"
Model for the main agent.
model.effortone of "low" "medium" "high" "xhigh" "max"default "high"
Sent as output_config.effort.
model.subagentIdstringdefault "claude-sonnet-5"
Default model for subagents.
model.thinkingone of "adaptive" "off"default "adaptive"
adaptive sends thinking: {type: "adaptive"}; off omits it.

tools

Each entry is one tool. The kind decides which binding object applies.

tools[].namestringrequired
Name the model sees.
tools[].descriptionstringdefault ""
When and how to use the tool. This is what the model reads to choose tools.
tools[].kindone of "http" "shell" "read_file" "write_file" "list_files" "search" "web_search" "web_fetch" "memory"required
How the tool runs. See tool kinds.
tools[].inputSchemaobject
JSON Schema (type: object) for the input. Keys starting with x- are decree annotations and are stripped before the API sees the schema.
tools[].readOnlyboolean
The tool does not change anything.
tools[].destructiveboolean
Hard to undo. Always needs approval under approvalMode: destructive.
tools[].requiresApprovalboolean
Ask a human before every call.
tools[].sourcestring
Where the tool came from, for example openapi:GET /orders or package.json#scripts.test.

Tool kinds

KindWhat it does
httpCalls an endpoint of your API. Bound from OpenAPI operations and routes found in code.
shellRuns a command template, usually a package script, with /bin/sh -c.
read_fileReads a file under fs.root, redacted and truncated.
write_fileWrites a file under fs.root. Left out when the goal does not call for code changes.
list_filesGlobs files, skipping node_modules, .git, build output and the generated agent/ directory.
searchRegex search across files, up to 200 matches as path:line: text.
web_searchAnthropic server tool, up to 5 uses per request.
web_fetchAnthropic server tool, up to 5 uses per request.
memoryAnthropic memory tool, confined to a memory directory.

tools[].http

tools[].http.methodone of "GET" "POST" "PUT" "PATCH" "DELETE" "HEAD" "OPTIONS"required
HTTP method.
tools[].http.baseUrlEnvstring
Env var holding the base URL. Defaults to <NAME>_BASE_URL.
tools[].http.defaultBaseUrlstring
Used when the env var is not set.
tools[].http.pathstringrequired
Path template, for example /users/{id}. Each {name} is URL-encoded from the input.
tools[].http.queryParamsstring[]
Input keys sent as query parameters.
tools[].http.headerParamsstring[]
Input keys sent as headers.
tools[].http.bodyParamstring
Input key sent as the JSON body. Without it, every input key not used elsewhere goes in the body.
tools[].http.auth.typeone of "bearer" "header" "none"required
bearer sends Authorization: Bearer $ENV; header sends auth.header: $ENV.
tools[].http.auth.envstring
Env var holding the credential.
tools[].http.auth.headerstring
Header name for header auth.

tools[].shell

tools[].shell.commandstringrequired
Command template. {{param}} placeholders are POSIX-quoted and must be bare shell words.
tools[].shell.cwdstring
Working directory, relative to the project root.
tools[].shell.timeoutMsinteger
Timeout. Default 120000.

tools[].fs

Used by read_file, write_file, list_files and search.

tools[].fs.rootstringdefault "."
Root the tool resolves paths against.
tools[].fs.maxBytesinteger
Max bytes read_file returns. Default 200000.

subagents

Each subagent becomes a tool on the main agent named delegate_to_<name> (dashes become underscores) that takes { "task": string } and returns the subagent's final text.

subagents[].namestringrequired
Subagent name. Exposed to the main agent as delegate_to_<name>.
subagents[].descriptionstringdefault ""
When the main agent should delegate.
subagents[].systemPromptstringrequired
The subagent's system prompt.
subagents[].toolsstring[]default []
Names of tools from tools the subagent may use.
subagents[].modelstring
Defaults to model.subagentId.
subagents[].effortone of "low" "medium" "high" "xhigh" "max"
Defaults to medium.

guardrails

guardrails.maxTurnsintegerdefault 40
Stop after this many model turns.
guardrails.maxOutputTokensPerTurnintegerdefault 32000
Sent as max_tokens.
guardrails.maxCostUsdnumber
Stop once the estimated cost of a run passes this.
guardrails.blockedCommandsstring[]default 18 entries
Shell commands containing any of these substrings are refused.
guardrails.allowedPathsstring[]default ["."]
File tools refuse paths outside these.
guardrails.redactEnvstring[]default []
Values of these env vars are replaced with [REDACTED:NAME] in tool output.
guardrails.approvalModeone of "always" "destructive" "never"default "destructive"
Which tools ask first. See approval.

Default blockedCommands: rm -rf /, rm -rf ~, rm -rf *, rm -rf ., git push --force, git push -f, git reset --hard, git clean -fd, DROP DATABASE, DROP TABLE, TRUNCATE TABLE, mkfs, dd if=, :(){ :|:& };:, chmod -R 777, shutdown, reboot, npm publish.

context

context.cachingbooleandefault true
Prompt caching on the system prompt and conversation tail.
context.compactionbooleandefault true
Server-side compaction for long sessions.
context.contextEditingbooleandefault false
Clears old tool results from the context.
context.memorybooleandefault false
Adds the Anthropic memory tool.

evals

evals[].idstringrequired
Unique id. eval --filter matches on it.
evals[].inputstringrequired
The user message.
evals[].expectobject
What must be true of the run.
evals[].tagsstring[]
Free-form labels.
evals[].expect.toolsCalledstring[]
Tools that must be called.
evals[].expect.toolsNotCalledstring[]
Tools that must not be called.
evals[].expect.containsstring[]
Strings the final answer must contain.
evals[].expect.notContainsstring[]
Strings the final answer must not contain.
evals[].expect.rubricstring
Graded by a Claude judge.

targets

Array of "typescript", "python", "mcp", "claude-code". The schema default is ["typescript", "claude-code"]; the --targets flag on init, plan and generate overrides it. See Targets.

env

env[].namestringrequired
Variable name.
env[].descriptionstringdefault ""
What it is for.
env[].requiredbooleandefault false
doctor warns when it is missing.
env[].secretbooleandefault false
Marks the value as a secret.
env[].defaultstring
Default value.

provenance

Written by decree; you do not need to edit it. generator is heuristic for offline plans and llm for Claude plans, and notes records the planner's reasoning, for example which scripts were skipped and why.
