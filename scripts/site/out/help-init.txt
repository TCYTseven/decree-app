Usage: decree-harness init [options] [dir]

scan, plan and generate a harness (the default command)

Options:
  -g, --goal <text>     what the agent should do, in your words
  -t, --targets <list>  comma-separated: typescript, python, mcp, claude-code (or all)
  --offline             use the heuristic planner instead of Claude
  -m, --model <id>      model for planning and the generated harness (default claude-opus-5)
  --no-critique         skip the critic pass (faster, cheaper)
  --api-key <key>       Anthropic API key (default: ANTHROPIC_API_KEY or .env)
  -o, --out <dir>       output directory for generated code (default: "agent")
  -y, --yes             non-interactive: accept defaults (automatic when not a TTY)
  -f, --force           re-plan an existing decree.json and overwrite files you edited
  --dry-run             show what would be written without writing anything
  -h, --help            show help
